# ESP32 + Micro:Bit 语音交互系统开源方案

## 硬件清单（含完整型号）
| 模块名称                  | 完整型号/参数                  | 数量 | 作用说明                     |
|---------------------------|--------------------------------|------|------------------------------|
| ESP32 开发板              | ESP32 DevKitC V4               | 1    | 主控制单元，负责联网和音频控制 |
| Micro:Bit 开发板          | Micro:Bit v1.5                 | 1    | 辅助控制，负责录音和用户交互   |
| 音频解码模块              | HW-261（内置 VS1053B 芯片）   | 1    | 解码音频信号，驱动喇叭播放     |
| 喇叭                      | HS-S49A-PL（8Ω 0.5W）          | 1    | 音频输出设备                 |
| 麦克风                    | FlyingFish 模拟麦克风（3.3V）  | 1    | 语音输入设备                 |
| 杜邦线                    | 20cm 单股杜邦线（公对母）      | 20根 | 模块间电路连接               |
| 电源适配器                | 5V 2A 直流电源（带Micro USB） | 1    | 为 ESP32 和 HW-261 供电      |

## 项目概述
本方案基于 ESP32 DevKit 和 Micro:Bit v1 开发板，实现了一套套低成本语音问答系统。通过麦克风克风采集语音指令，联网调用 API 获取回答，并通过 VS1053 音频模块（HW-261）驱动喇叭播放结果，支持循环问答交互。
## 软件准备
### 1. 开发环境
- **ESP32**：Arduino IDE（需安装 ESP32 开发板支持）
- **Micro:Bit**：Mu Editor 或 MakeCode（推荐 MicroPython 环境）

### 2. 依赖库（ESP32）
- `WiFi.h`：ESP32 内置 WiFi 库
- `ArduinoJson.h`：JSON 数据处理（建议版本 6.x）
- `HTTPClient.h`：HTTP 请求处理
- `SPI.h`：SPI 通信协议库

### 3. 代码上传
1. **ESP32 代码**：
   - 打开 Arduino IDE，导入 `esp32_vs1053_system.ino`
   - 配置 WiFi 名称和密码（`WIFI_SSID`、`WIFI_PASSWORD`）
   - 配置 API 密钥（`QINGYU_API_KEY`）
   - 选择开发板型号（`ESP32 Dev Module`）和端口，上传代码

2. **Micro:Bit 代码**：
   - 打开 Mu Editor，导入 `microbit_voice_control.py`
   - 连接 Micro:Bit，点击"Flash"上传代码

## 使用说明
1. **系统启动**：
   - 连接所有硬件并供电，ESP32 将自动启动并尝试连接 WiFi，WIFi名称是smart speaker，密码为alpine
   - Micro:Bit 屏幕显示等待图标（左箭头），表示系统就绪

2. **语音问答流程**：
   - **触发录音**：按下 Micro:Bit 的 A 键或 B 键，屏幕显示上箭头图标，麦克风开始录音
   - **录音过程**：录音持续 1 秒（可通过代码 `RECORD_DURATION` 修改）
   - **处理状态**：录音结束后，屏幕显示方框图标，ESP32 开始联网请求回答
   - **播放回答**：获取回答后，喇叭自动播放内容，播放完成后系统回到等待状态
   - **循环交互**：重复按下 A/B 键可触发新一轮问答

3. **状态指示**：
   - 上箭头：录音中
   - 方框：处理中（联网请求）
   - 左箭头：等待指令
   - 对勾：操作成功
   - 叉号：操作失败

## 故障排查指南
### 常见问题及解决方法
1. **SPI 通信异常**（日志显示寄存器读取失败）：
   - 检查 SCK/MISO/MOSI 接线是否正确（必须对应 GPIO18/19/23）
   - 更换 SPI 三线杜邦线（优先用新线）
   - 确认 HW-261 供电电压为 5V（用万用表测量）
   - 降低 SPI 频率（修改代码 `VS1053_SPI_FREQ` 为 125000）

2. **录音无响应**：
   - 检查麦克风接线（VCC 接 3V，AO 接 pin0）
   - 确认 Micro:Bit 已正确上传代码并供电
   - 尝试靠近麦克风说话（音量适中）

3. **喇叭无声音**：
   - 检查喇叭与 HW-261 的接线（V 接 5V，G 接 GND，R 接音频输出）
   - 确认 HW-261 初始化成功（日志无"模块不可用"警告）
   - 提高音量（修改代码 `vs1053_write_register(VS1053_REG_VOL, 0x4040)`）

4. **WiFi 连接失败**：
   - 检查 WiFi 名称和密码是否正确
   - 确认 ESP32 在 WiFi 信号范围内
   - 尝试更换 2.4GHz WiFi（不支持 5GHz）

UART_RX_PIN = pin19                # UART接收引脚

CMD_RECORD_START = b"R"            # 开始录音
CMD_RECORD_END = b"r"              # 结束录音
CMD_TEXT = b"T"                    # 文本回答
CMD_SPEECH = b"S"                  # 语音回答
CMD_DONE = b"D"                    # 操作完成
CMD_ERROR = b"E"                   # 操作错误

# 音频参数
SAMPLE_RATE = 2000                 # 采样率（Hz）
RECORD_DURATION = 1                # 录音时长（秒）
SAMPLE_COUNT = SAMPLE_RATE * RECORD_DURATION  # 总采样数
SAMPLE_INTERVAL = 1000000 // SAMPLE_RATE      # 采样间隔（微秒）

# 初始化串口（115200波特率）
uart.init(baudrate=115200, tx=UART_TX_PIN, rx=UART_RX_PIN)


def send_byte(b: int) -> None:
    """发送单字节数据到ESP32"""
    uart.write(bytes([b]))


def record_and_stream() -> None:
    """录音并通过UART流式发送音频数据"""
    display.show(IMAGE_LISTEN)
    send_byte(ord(CMD_RECORD_START))  # 发送开始录音指令

    # 显示状态切换（避免频繁刷新）
    is_display_on = True
    progress_counter = 0

    for i in range(SAMPLE_COUNT):
        # 采集麦克风模拟值并转换为PCM格式
        analog_val = MIC_PIN.read_analog()
        pcm_val = int((analog_val - 512) / 4)  # 归一化到-128~127
        pcm_val = max(-128, min(127, pcm_val))  # 限幅
        byte_val = pcm_val + 128  # 转换为0~255字节

        # 发送音频字节
        send_byte(byte_val)

        # 周期性切换显示（避免屏幕闪烁）
        progress_counter += 1
        if progress_counter % 1000 == 0:
            if is_display_on:
                display.clear()
            else:
                display.show(IMAGE_LISTEN)
            is_display_on = not is_display_on
        utime.sleep_us(SAMPLE_INTERVAL)  # 控制采样间隔

    send_byte(ord(CMD_RECORD_END))  # 发送结束录音指令
    display.clear()


def play_pcm_stream(pcm_data: bytes) -> None:
    """播放从ESP32接收的PCM音频数据"""
    display.show(IMAGE_SPEAKER)
    data_len = len(pcm_data)

    for i in range(data_len):
        # 转换PCM字节为PWM占空比
        pcm_sample = pcm_data[i] - 128  # 还原为-128~127
        duty = (pcm_sample + 128) * 1023 // 255  # 映射到0~1023
        duty = 0 if duty < 0 else 1023 if duty > 1023 else duty

        SPEAKER_PIN.write_analog(duty)  # 输出PWM信号
        utime.sleep_us(SAMPLE_INTERVAL)
    SPEAKER_PIN.write_analog(0)  # 停止输出
    display.clear()

                record_and_stream()  # 执行录音
                display.show(IMAGE_WAITING)  # 等待ESP32处理
                state = "receive"
        elif state == "receive":
            # 接收ESP32的处理结果
            if uart.any():
                data = uart.read(1)
                if not data:
                    continue
                if data == CMD_TEXT:
                    # 接收文本回答并滚动显示
                    text_bytes = bytearray()
                    while True:
                        c = uart.read(1)
                        if c == b"\n":
                            break
                        text_bytes.append(c[0])
                    text = text_bytes.decode("utf-8", errors="replace")[:30]  # 限制长度
                    display.scroll(text)
                    del text_bytes, text  # 释放内存
                elif data == CMD_SPEECH:
                    # 接收语音数据并播放
                    pcm_bytes = bytearray()
                    while True:
                        c = uart.read(1)
                        if c == b"\n":
                            break
                        pcm_bytes.append(c[0])
                    play_pcm_stream(pcm_bytes)
                    send_byte(ord(CMD_DONE))  # 通知播放完成
                    del pcm_bytes
                elif data == CMD_DONE:
                    # 处理完成，回到等待状态
                    display.show(IMAGE_SUCCESS)
                    utime.sleep(1)
                    state = "wait"
                    display.show(IMAGE_WAIT)
                elif data == CMD_ERROR:

                    display.show(IMAGE_FAILURE)
                    utime.sleep(2)
                    state = "wait"
                    display.show(IMAGE_WAIT)
                del data  # 释放内存
        utime.sleep_ms(100)  # 降低CPU占用

// -------------------------- 3. 基础SPI工具函数 --------------------------
void vs1053_write_register(uint8_t reg, uint16_t value) {
    // 向VS1053寄存器写入值
    digitalWrite(VS1053_XCS, LOW);  // 选中芯片
    SPI.transfer(VS1053_CMD_WRITE);  // 发送写指令
    SPI.transfer(reg);               // 寄存器地址
    SPI.transfer((value >> 8) & 0xFF);  // 高8位
    SPI.transfer(value & 0xFF);        // 低8位
    digitalWrite(VS1053_XCS, HIGH); // 取消选中
    delay(10);  // 等待写入完成
}

uint16_t vs1053_read_register(uint8_t reg) {
    // 从VS1053寄存器读取值
    digitalWrite(VS1053_XCS, LOW);  // 选中芯片
    SPI.transfer(VS1053_CMD_READ);   // 发送读指令
    SPI.transfer(reg);               // 寄存器地址
    uint16_t high = SPI.transfer(0x00);  // 读高8位
    uint16_t low = SPI.transfer(0x00);   // 读低8位
    digitalWrite(VS1053_XCS, HIGH); // 取消选中
    return (high << 8) | low;       // 合并为16位值
}

void checkModuleResponse() {
    // 检测VS1053模块响应及芯片信息
    Serial.println("\n[自检2/4] 详细检测模块响应状态...");
    isModuleOk = false;
    
    // 读取状态寄存器（0x01）
    uint16_t status = vs1053_read_register(VS1053_REG_STATUS);
    uint8_t manufacturerID = (status >> 12) & 0x0F;  // 制造商ID（VS1053应为0x00）
    uint8_t chipID = (status >> 8) & 0x0F;           // 芯片ID（VS1053应为0x03）
    Serial.printf("  状态寄存器：0x%04X → 制造商ID=0x%01X，芯片ID=0x%01X\n", 
                 status, manufacturerID, chipID);

    // 读取模式寄存器（0x00）确认复位状态
    uint16_t mode = vs1053_read_register(VS1053_REG_MODE);
    bool isResetDone = (mode & VS1053_MODE_SM_RESET) == 0;
    Serial.printf("  模式寄存器：0x%04X → 软件复位%s\n", 
                 mode, isResetDone ? "完成" : "未完成");

    // 综合判断：芯片ID正确且复位完成
    if (chipID == 0x03 && isResetDone) {
        Serial.println("[自检2/4] 模块响应正常");
        isModuleOk = true;
    } else {
        Serial.println("[自检2/4] 模块响应异常！可能原因：");
        Serial.println("  - 模块供电不足（必须5V，当前可能为3.3V或电压不稳）");
        Serial.println("  - RESET引脚接线错误或未执行有效复位");
        Serial.println("  - 模块硬件故障（可尝试更换模块测试）");
    }
}

void checkDREQPin() {

    vs1053_write_register(VS1053_REG_AUDATA, 0xAC44);  // 44.1kHz, 16bit
    delay(100);
    bool afterWriteState = digitalRead(VS1053_DREQ) == HIGH;
    Serial.printf("  发送配置后：%s\n", 
                 afterWriteState ? "高电平（就绪）" : "低电平（忙碌）");

    // 综合判断：至少有一次高电平表示引脚可用
    if (initialState || afterWriteState) {
        Serial.println("[自检3/4] DREQ引脚功能正常");
        isDREQOk = true;
    } else {
        Serial.println("[自检3/4] DREQ引脚异常！可能原因：");
        Serial.println("  - DREQ引脚未连接到ESP32的GPIO4");
        Serial.println("  - 模块未上电或处于永久忙碌状态");
        Serial.println("  - 引脚定义错误（代码中DREQ引脚是否为GPIO4）");
    }
}

void checkCSpins() {
    // 检测XCS/XDCS片选控制引脚功能
    Serial.println("\n[自检4/4] 详细检测XCS/XDCS控制功能...");
    isCSOk = false;
    
    // 测试XCS控制
    digitalWrite(VS1053_XCS, LOW);  // 选中
    uint16_t modeWhenSelected = vs1053_read_register(VS1053_REG_MODE);
    digitalWrite(VS1053_XCS, HIGH); // 取消选中
    delay(50);
    uint16_t modeWhenUnselected = vs1053_read_register(VS1053_REG_MODE);
    Serial.printf("  XCS控制测试：选中时=0x%04X，未选中时=0x%04X → %s\n", 
                 modeWhenSelected, modeWhenUnselected, 
                 (modeWhenSelected != modeWhenUnselected) ? "有差异（正常）" : "无差异（异常）");

    // 测试XDCS控制（通过读写数据寄存器验证）
    digitalWrite(VS1053_XDCS, LOW);
    SPI.transfer(0x00);  // 发送空数据
    digitalWrite(VS1053_XDCS, HIGH);
    bool xdcsResponse = digitalRead(VS1053_DREQ) == HIGH;
    Serial.printf("  XDCS控制测试：操作后DREQ状态=%s → %s\n",
                 xdcsResponse ? "高电平" : "低电平",
                 xdcsResponse ? "正常" : "异常");

    // 综合判断：XCS切换有差异即视为基本正常
    if (modeWhenSelected != modeWhenUnselected) {
        Serial.println("[自检4/4] XCS/XDCS控制功能正常");
        isCSOk = true;
    } else {
        Serial.println("[自检4/4] XCS/XDCS控制异常！可能原因：");
        Serial.println("  - XCS未接GPIO5或XDCS未接GPIO2");
        Serial.println("  - 杜邦线接触不良（建议更换新线）");
        Serial.println("  - 引脚被其他功能占用（检查是否与其他模块冲突）");
    }
}

void initVS1053() {
    // 初始化VS1053模块（不中断程序）
    Serial.println("\n初始化VS1053模块...");
    
    // 引脚模式初始化
    pinMode(VS1053_XCS, OUTPUT);
    pinMode(VS1053_XDCS, OUTPUT);
    pinMode(VS1053_DREQ, INPUT);
    pinMode(VS1053_RESET, OUTPUT);
    
    // 硬件复位（详细步骤）
    Serial.println("  执行硬件复位...");
    digitalWrite(VS1053_RESET, HIGH);
    delay(100);
    digitalWrite(VS1053_RESET, LOW);
    delay(500);
    digitalWrite(VS1053_RESET, HIGH);
    delay(500);

    // SPI初始化（1MHz频率）
    SPI.begin(VS1053_SCK, VS1053_MISO, VS1053_MOSI);
    SPI.setFrequency(1000000);
    Serial.println("  SPI初始化完成（1MHz）");

    // 软件复位
    Serial.println("  执行软件复位...");
    vs1053_write_register(VS1053_REG_MODE, VS1053_MODE_SM_RESET | VS1053_MODE_SM_SDINEW);
    delay(100);

    // 配置时钟（48MHz）
    vs1053_write_register(VS1053_REG_CLOCKF, 0x9800);
    delay(100);

    Serial.println("VS1053初始化流程完成（无论结果如何继续）");
}

String getQingyuTextAnswer(const String& user_question) {
    // 调用轻语API获取文本回答
    if (WiFi.status() != WL_CONNECTED) {
        Serial.println("警告：WiFi未连接，无法请求API");
        return "网络未连接";
    }

    String answer = "暂未获取到回答";
    if (user_question.isEmpty()) return answer;

    WiFiClientSecure httpsClient;
    httpsClient.setInsecure();  // 忽略SSL证书验证（测试用）
    HTTPClient http;

    if (!http.begin(httpsClient, QINGYU_TEXT_URL)) {
        Serial.println("API请求失败：HTTP初始化错误");
        return answer;
    }
    http.addHeader("Content-Type", "application/json");
    http.addHeader("apikey", QINGYU_API_KEY);

    // 构建请求JSON
    DynamicJsonDocument reqDoc(1024);
    reqDoc["question"] = user_question;
    reqDoc["response_type"] = "text";
    String reqBody;
    serializeJson(reqDoc, reqBody);

    // 发送POST请求
    int httpCode = http.POST(reqBody);
    if (httpCode == HTTP_CODE_OK) {
        String resp = http.getString();
        DynamicJsonDocument respDoc(1024);
        DeserializationError err = deserializeJson(respDoc, resp);
        if (!err && respDoc["code"].as<int>() == 200) {
            answer = respDoc["answer"].as<String>();
        } else {
            Serial.println("API响应解析失败");
        }
    } else {
        Serial.printf("API请求失败，状态码：%d\n", httpCode);
    }
    http.end();
    return answer;
}

void loop() {
    // 处理Micro:Bit发送的指令
    if (UART_MICROBIT.available()) {
        uint8_t cmd = UART_MICROBIT.read();
        if (cmd == CMD_RECORD_END) {
            Serial.println("\n收到录音结束指令");

            // 示例：固定问题（实际应从音频解析）
            String userQuestion = "今天天气怎么样？";
            String answer = getQingyuTextAnswer(userQuestion);
            Serial.printf("回答：%s\n", answer.c_str());

            // 播放回答音频
            vs1053_play_mp3(MP3_FILENAME);

            Serial.println("\n处理完成，等待下一条指令");
        }
    }
    
    // 每5秒检测一次DREQ状态
    static unsigned long lastCheckTime = 0;
    if (millis() - lastCheckTime > 5000) {
        lastCheckTime = millis();
        bool currentDreq = digitalRead(VS1053_DREQ) == HIGH;
        if (!currentDreq) {
            Serial.println("状态提示：DREQ引脚当前为低电平（模块忙碌）");
        }
    }

    delay(100);
}
