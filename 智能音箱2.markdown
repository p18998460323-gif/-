# ESP32 + Micro:Bit 语音交互系统开源方案

## 硬件清单（含完整型号）
| 模块名称                  | 完整型号/参数                  | 数量 | 作用说明                     |
|---------------------------|--------------------------------|------|------------------------------|
| ESP32 开发板              | ESP32 DevKitC V4               | 1    | 主控制单元，负责联网和音频控制 |
| Micro:Bit 开发板          | Micro:Bit v1.5                 | 1    | 辅助控制，负责录音和用户交互   |
| 音频解码模块              | HW-261（内置 VS1053B 芯片）   | 1    | 解码音频信号，驱动喇叭播放     |
| 喇叭                      | HS-S49A-PL（8Ω 0.5W）          | 1    | 音频输出设备，接收VS1053解码后的模拟信号 |
| 麦克风                    | FlyingFish 模拟麦克风（3.3V）  | 1    | 语音输入设备                 |
| 杜邦线                    | 20cm 单股杜邦线（公对母）      | 20根 | 模块间电路连接               |
| 电源适配器                | 5V 2A 直流电源（带Micro USB） | 1    | 为 ESP32 和 HW-261 供电      |

## 项目概述
本方案基于 ESP32 DevKit 和 Micro:Bit v1 开发板，实现了一套低成本语音问答系统。通过麦克风采集语音指令，联网调用 API 获取回答，并通过 VS1053 音频模块（HW-261）解码后驱动喇叭播放结果，支持循环问答交互。

## 软件准备
### 1. 开发环境
- **ESP32**：Arduino IDE（需安装 ESP32 开发板支持）
- **Micro:Bit**：Mu Editor 或 MakeCode（推荐 MicroPython 环境）

### 2. 依赖库（ESP32）
- `WiFi.h`：ESP32 内置 WiFi 库
- `ArduinoJson.h`：JSON 数据处理（建议版本 6.x）
- `HTTPClient.h`：HTTP 请求处理
- `SPI.h`：SPI 通信协议库
- `WebSocketsClient.h`：WebSocket 通信库（星火大模型调用）

### 3. 代码上传
1. **ESP32 代码**：
   - 打开 Arduino IDE，导入修正后的 `esp32_vs1053_system.ino`
   - 配置 WiFi 名称和密码（`WIFI_SSID`、`WIFI_PASSWORD`）
   - 配置 API 密钥（`API_KEY`）及星火大模型鉴权信息
   - 选择开发板型号（`ESP32 Dev Module`）和端口，上传代码

2. **Micro:Bit 代码**：
   - 打开 Mu Editor，导入修正后的 `microbit_voice_control.py`
   - 连接 Micro:Bit，点击"Flash"上传代码

| MISO       | SPI 数据输入 | GPIO33   | 避开SDIO冲突引脚           |
| MOSI       | SPI 数据输出 | GPIO25   | 避开SDIO冲突引脚           |
| XCS        | 芯片选择   | GPIO5     |                          |
| XDCS       | 数据选择   | GPIO2     |                          |
| DREQ       | 数据请求   | GPIO4     | 模块就绪信号（高电平有效） |

| Micro:Bit 引脚 | 功能       | ESP32 引脚 | 备注                     |

| pin19（RX）   | UART 接收  | GPIO17    | 硬件UART2发送（交叉连接）|
| 3V            | 电源正极   | 3V3       | 为 Micro:Bit 供电（3.3V） |
| GND           | 电源负极   | GND       | 与系统共地               |

### 3. 麦克风 ↔ Micro:Bit
| 麦克风引脚 | 功能       | Micro:Bit 引脚 | 备注                     |
|------------|------------|---------------|--------------------------|
| VCC        | 电源正极   | 3V            | 3.3V 供电                |
| GND        | 电源负极   | GND           | 共地                     |
| AO         | 模拟输出   | pin0          | 音频信号输入             |

### 4. 喇叭 ↔ HW-261
| 喇叭引脚 | 功能       | HW-261 接口    | 备注                     |
|----------|------------|---------------|--------------------------|
| V        | 电源正极   | 5V            | 与 HW-261 共用 5V 供电   |
| G        | 电源负极   | GND           | 共地                     |
| R        | 音频输入   | 3.5mm 耳机孔   | 通过杜邦线转接至HS-S49A-PL的信号接收引脚 |

## 使用说明
1. **系统启动**：
   - 连接所有硬件并供电，ESP32 将自动启动并尝试连接 WiFi，WiFi名称和密码需在代码中配置
   - Micro:Bit 屏幕显示等待图标（左箭头），表示系统就绪

2. **语音问答流程**：
   - **触发录音**：按下 Micro:Bit 的 A 键，屏幕显示上箭头图标，麦克风开始录音
   - **录音过程**：录音持续 5 秒（可通过代码 `RECORD_DURATION` 修改），支持 B 键暂停/继续
   - **处理状态**：录音结束后，屏幕显示方框图标，ESP32 开始联网请求回答
   - **播放回答**：获取回答后，喇叭自动播放内容，播放过程支持 B 键暂停/继续，播放完成后系统回到等待状态
   - **循环交互**：重复按下 A 键可触发新一轮问答

3. **状态指示**：
   - 上箭头：录音中
   - 方框：处理中（联网请求）
   - 左箭头：等待指令
   - 对勾：操作成功
   - 叉号：操作失败
   - 哭脸：暂停状态

## 故障排查指南
### 常见问题及解决方法
1. **SPI 通信异常**（日志显示寄存器读取失败）：
   - 检查 SCK/MISO/MOSI 接线是否正确（必须对应 GPIO26/33/25）
   - 更换 SPI 三线杜邦线（优先用新线）
   - 确认 HW-261 供电电压为 5V（用万用表测量）
   - 降低 SPI 频率（修改代码中 `SPI.setFrequency` 为 250000）

2. **录音无响应**：
   - 检查麦克风接线（VCC 接 3V，AO 接 pin0）
   - 确认 Micro:Bit 已正确上传代码并供电
   - 尝试靠近麦克风说话（音量适中）

3. **喇叭无声音**：
   - 检查喇叭与 HW-261 的接线（V 接 5V，G 接 GND，R 接音频输出）
   - 确认 HW-261 初始化成功（日志无"模块不可用"警告）
   - 调整音量（修改代码中 `vs1053WriteReg(VS1053_REG_VOL, 0x4040)` 的值，减小数值可增大音量）

4. **WiFi 连接失败**：
   - 检查 WiFi 名称和密码是否正确
   - 确认 ESP32 在 WiFi 信号范围内
   - 尝试更换 2.4GHz WiFi（不支持 5GHz）

5. **UART 通信异常**：
   - 检查 Micro:Bit 与 ESP32 的 TX/RX 接线是否交叉（TX→RX，RX→TX）
   - 确认串口波特率为 115200
   - 尝试短接 ESP32 的 TX/RX 引脚，测试环回通信

**功能**：录音控制、UART 通信、状态显示

```python
from microbit import *
import utime

IMAGE_LISTEN = Image.ARROW_N
IMAGE_SPEAKER = Image.ARROW_S
IMAGE_WAIT = Image.ARROW_W
IMAGE_PROCESS = Image.ARROW_E
IMAGE_WAITING = Image.SQUARE
IMAGE_SUCCESS = Image.YES
IMAGE_FAILURE = Image.NO
IMAGE_PAUSED = Image.SAD

MIC_PIN = pin0
SPEAKER_PIN = pin1
UART_TX_PIN = pin20
UART_RX_PIN = pin19

CMD_RECORD_START = b"R"
CMD_RECORD_END = b"r"
CMD_TEXT = b"T"
CMD_SPEECH = b"S"
CMD_DONE = b"D"
CMD_ERROR = b"E"

SAMPLE_RATE = 2000
RECORD_DURATION = 5
SAMPLE_COUNT = SAMPLE_RATE * RECORD_DURATION
SAMPLE_INTERVAL = 1000000 // SAMPLE_RATE

uart.init(baudrate=115200, tx=UART_TX_PIN, rx=UART_RX_PIN)

def send_byte(b: int) -> None:
    uart.write(bytes([b]))

def record_and_stream() -> None:
    display.show(IMAGE_LISTEN)
    send_byte(ord(CMD_RECORD_START))

    is_display_on = True
    progress_counter = 0
    paused = False

    for i in range(SAMPLE_COUNT):
        if button_b.was_pressed():
            paused = not paused
            if paused:
                display.show(IMAGE_PAUSED)
            else:
                display.show(IMAGE_LISTEN)
            while paused:
                if button_b.was_pressed():
                    paused = False
                    display.show(IMAGE_LISTEN)
                utime.sleep_ms(100)

        analog_val = MIC_PIN.read_analog()
        pcm_val = int((analog_val - 512) / 4)
        pcm_val = max(-128, min(127, pcm_val))
        byte_val = pcm_val + 128

        send_byte(byte_val)

        progress_counter += 1
        if progress_counter % 1000 == 0:
            if is_display_on:
                display.clear()
            else:
                display.show(IMAGE_LISTEN)
            is_display_on = not is_display_on
        utime.sleep_us(SAMPLE_INTERVAL)
    send_byte(ord(CMD_RECORD_END))
    display.clear()

def play_pcm_stream(pcm_data: bytes) -> None:
    display.show(IMAGE_SPEAKER)
    data_len = len(pcm_data)
    paused = False

    for i in range(data_len):
        if button_b.was_pressed():
            paused = not paused
            if paused:
                display.show(IMAGE_PAUSED)
            else:
                display.show(IMAGE_SPEAKER)
            while paused:
                if button_b.was_pressed():
                    paused = False
                    display.show(IMAGE_SPEAKER)
                utime.sleep_ms(100)

        pcm_sample = pcm_data[i] - 128
        duty = (pcm_sample + 128) * 1023 // 255
        duty = 0 if duty < 0 else 1023 if duty > 1023 else duty

        SPEAKER_PIN.write_analog(duty)
        utime.sleep_us(SAMPLE_INTERVAL)
    SPEAKER_PIN.write_analog(0)
    display.clear()

def main() -> None:
    state = "wait"
    prev_state = None
    display.show(IMAGE_WAIT)

    while True:
        if button_b.was_pressed():
            if state != "paused":
                prev_state = state
                state = "paused"
                display.show(IMAGE_PAUSED)
            else:
                if prev_state is not None:
                    state = prev_state
                    if state == "wait":
                        display.show(IMAGE_WAIT)
                    elif state == "receive":
                        display.show(IMAGE_WAITING)
                prev_state = None

        if state == "paused":
            utime.sleep_ms(100)
            continue

        if state == "wait":
            if button_a.was_pressed():
                display.show(IMAGE_PROCESS)
                record_and_stream()
                display.show(IMAGE_WAITING)
                state = "receive"
        elif state == "receive":
            if uart.any():
                data = uart.read(1)
                if not data:
                    continue
                if data == CMD_TEXT:
                    text_bytes = bytearray()
                    while True:
                        c = uart.read(1)
                        if c == b"\n":
                            break
                        text_bytes.append(c[0])
                    text = text_bytes.decode("utf-8", errors="replace")[:3]
                    display.scroll(text)
                    del text_bytes, text
                elif data == CMD_SPEECH:
                    pcm_bytes = bytearray()
                    while True:
                        c = uart.read(1)
                        if c == b"\n":
                            break
                        pcm_bytes.append(c[0])
                    play_pcm_stream(pcm_bytes)
                    send_byte(ord(CMD_DONE))
                    del pcm_bytes
                elif data == CMD_DONE:
                    display.show(IMAGE_SUCCESS)
                    utime.sleep(1)
                    state = "wait"
                    display.show(IMAGE_WAIT)
                elif data == CMD_ERROR:
                    display.show(IMAGE_FAILURE)
                    utime.sleep(2)
                    state = "wait"
                    display.show(IMAGE_WAIT)
                del data
        utime.sleep_ms(100)

if __name__ == "__main__":
    main()
```

String base64Encode(const uint8_t* data, size_t length) {
  const String base64Chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/";
  String result;
  int i = 0;
  uint8_t charArray3[3];
  uint8_t charArray4[4];

  while (length--) {
    charArray3[i++] = *(data++);
    if (i == 3) {
      charArray4[0] = (charArray3[0] & 0xfc) >> 2;
      charArray4[1] = ((charArray3[0] & 0x03) << 4) + ((charArray3[1] & 0xf0) >> 4);
      charArray4[2] = ((charArray3[1] & 0x0f) << 2) + ((charArray3[2] & 0xc0) >> 6);
      charArray4[3] = charArray3[2] & 0x3f;

      for (i = 0; i < 4; i++) result += base64Chars[charArray4[i]];
      i = 0;
    }
  }

  if (i > 0) {
    for (int j = i; j < 3; j++) charArray3[j] = '\0';
    charArray4[0] = (charArray3[0] & 0xfc) >> 2;
    charArray4[1] = ((charArray3[0] & 0x03) << 4) + ((charArray3[1] & 0xf0) >> 4);
    charArray4[2] = ((charArray3[1] & 0x0f) << 2) + ((charArray3[2] & 0xc0) >> 6);
    charArray4[3] = 64;

    for (int j = 0; j < i + 1; j++) result += base64Chars[charArray4[j]];
    while (i++ < 3) result += '=';
  }
  return result;
}

String hmacSha256(const String& key, const String& data) {
  mbedtls_md_context_t ctx;
  mbedtls_md_type_t md_type = MBEDTLS_MD_SHA256;
  const size_t keyLen = key.length();
  const size_t dataLen = data.length();
  uint8_t hash[32];

  mbedtls_md_init(&ctx);
  if (mbedtls_md_setup(&ctx, mbedtls_md_info_from_type(md_type), 1) != 0) {
    mbedtls_md_free(&ctx);
    return "";
  }
  if (mbedtls_md_hmac_starts(&ctx, (const uint8_t*)key.c_str(), keyLen) != 0) {
    mbedtls_md_free(&ctx);
    return "";
  }
  mbedtls_md_hmac_update(&ctx, (const uint8_t*)data.c_str(), dataLen);
  mbedtls_md_hmac_finish(&ctx, hash);
  mbedtls_md_free(&ctx);

  return base64Encode(hash, 32);
}

String generateSparkAuthHeader() {
  time_t now = time(nullptr);
  struct tm tm = *gmtime(&now);
  char date[32];
  strftime(date, sizeof(date), "%a, %d %b %Y %H:%M:%S GMT", &tm);

  String signatureOrigin = String(SPARK_HOST) + "\n" + String(date) + "\n" + String(SPARK_REQUEST_LINE);
  String signature = hmacSha256(SPARK_API_SECRET, signatureOrigin);

  String authHeader = "api_key=\"" + String(SPARK_API_KEY) + "\",";
  authHeader += "algorithm=\"hmac-sha256\",";
  authHeader += "headers=\"host date request-line\",";
  authHeader += "signature=\"" + signature + "\"";

  return authHeader;
}

void webSocketEvent(WStype_t type, uint8_t* payload, size_t length) {
  switch (type) {
    case WStype_TEXT: {
      String resp = (char*)payload;
      DynamicJsonDocument respDoc(2048);
      deserializeJson(respDoc, resp);

      if (respDoc["header"]["code"].as<int>() == 0) {
        String content = respDoc["payload"]["choices"]["text"][0]["content"].as<String>();
        sparkAnswer += content;

        if (respDoc["payload"]["choices"]["text"][0]["is_end"].as<int>() == 1) {
          sparkCompleted = true;
        }
      } else {
        Serial.printf("星火API错误：%s\n", respDoc["header"]["message"].as<String>().c_str());
        sparkCompleted = true;
      }
      break;
    }
    case WStype_DISCONNECTED:
      Serial.println("星火WS连接断开");
      sparkCompleted = true;
      break;
    default:
      break;
  }
}

String sparkLiteQuery(String question) {
  if (question.isEmpty()) return "";

  sparkAnswer = "";
  sparkCompleted = false;

  String authHeader = generateSparkAuthHeader();
  if (authHeader.isEmpty()) {
    Serial.println("星火鉴权头生成失败");
    return "";
  }

  webSocket.begin(SPARK_HOST, 443, SPARK_WS_URL);
  webSocket.setReconnectInterval(1000);
  webSocket.onEvent(webSocketEvent);

  String extraHeaders = "Authorization: " + authHeader + "\r\nHost: " + SPARK_HOST + "\r\n";
  webSocket.setExtraHeaders(extraHeaders.c_str());

  Serial.println("连接星火WS...");
  uint32_t startTime = millis();

  while (millis() - startTime < SPARK_WS_TIMEOUT) {
    webSocket.loop();

    if (webSocket.isConnected() && sparkAnswer.isEmpty()) {
      Serial.println("星火WS连接成功，发送请求...");
      DynamicJsonDocument reqDoc(1024);
      reqDoc["appid"] = SPARK_APPID;
      reqDoc["version"] = "v1.1";
      reqDoc["role"] = "user";
      reqDoc["content"] = question;
      reqDoc["temperature"] = 0.7;
      reqDoc["max_tokens"] = 512;

      String reqBody;
      serializeJson(reqDoc, reqBody);
      webSocket.sendTXT(reqBody);
    }

    if (sparkCompleted) break;
    delay(50);
  }

  webSocket.disconnect();
  if (sparkAnswer.isEmpty()) {
    Serial.println("星火API无有效响应");
    return "";
  }

  Serial.printf("星火模型回答：%s\n", sparkAnswer.c_str());
  return sparkAnswer;
}

String urlEncode(const String& str) {
  String encoded;
  const char* hex = "0123456789ABCDEF";
  for (char c : str) {
    if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z') || (c >= '0' && c <= '9') || 
        c == '-' || c == '_' || c == '.' || c == '~') {
      encoded += c;
    } else {
      encoded += '%';
      encoded += hex[(c >> 4) & 0x0F];
      encoded += hex[c & 0x0F];
    }
  }
  return encoded;
}

void vs1053WriteReg(uint8_t reg, uint16_t value) {
  while (digitalRead(VS1053_DREQ) == LOW) delay(1);
  digitalWrite(VS1053_XCS, LOW);
  SPI.transfer(0x02);
  SPI.transfer(reg);
  SPI.transfer((value >> 8) & 0xFF);
  SPI.transfer(value & 0xFF);
  digitalWrite(VS1053_XCS, HIGH);
  delay(10);
}
